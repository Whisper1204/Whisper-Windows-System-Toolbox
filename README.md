## 为什么是它

网上很多“系统优化工具”要么捆绑全家桶，要么改完没法还原。这个工具的原则很简单：

| 原则 | 做法 |
| :-- | :-- |
| **单文件** | 只有一个 `.bat`，不安装、不写服务、不留后台进程 |
| **零依赖** | 只用系统自带的 `cmd`、`reg`、`sc`、`DISM`、`sfc` 和 PowerShell，不下载任何东西 |
| **可回滚** | 所有可逆改动集中在 `[8] 恢复与日志 → 一键恢复全部设置`，7 步还原 |
| **有记录** | 每次操作写入 `C:\ProgramData\WinToolbox\all.log`，事后可查 |
| **敢确认** | 高风险操作要求连续输入两次 `YES`，并逐项说明影响 |
| **不硬来** | 受系统保护的服务/任务会显示“已跳过”而不是报错中断 |

> [!NOTE]
> 工具不联网、不上传任何数据，也不包含任何广告或推广。

## 功能一览

### 1. 清理与空间（9 项）

| # | 功能 | 说明 |
| :-: | :-- | :-- |
| 1 | 一键清理 C 盘垃圾 | 临时文件、更新缓存、浏览器缓存、日志、回收站、Prefetch、WER、缩略图，共 9 类，并显示前后空间对比 |
| 2 | DISM 组件存储清理 | 分析 / 清理旧组件 / `/ResetBase` 三档，通常释放 1–5 GB |
| 3 | 内存转储与日志清理 | `MEMORY.DMP`、Minidump、LiveKernelReports、CBS 与 DISM 日志 |
| 4 | 清理 Windows.old | 取所有权后删除升级备份，通常释放 10–30 GB |
| 5 | 传递优化缓存 | 清理 P2P 分发缓存 |
| 6 | 保留存储开关 | 查看 / 关闭 / 开启系统预留的约 7 GB |
| 7 | 磁盘优化与 TRIM | 按介质类型自动选择，SSD 发 TRIM，HDD 整理碎片 |
| 8 | 还原点管理 | 列出、删除最旧、删除全部、新建 |
| 9 | 创建系统还原点 | 支持自动开启系统保护后重试 |

### 2. 系统与更新（8 项）

| # | 功能 | 说明 |

## 快速开始

### 1. 获取文件

```bash
git clone https://github.com/<your-name>/windows-toolbox.git
cd windows-toolbox
```

也可以直接下载仓库 ZIP，解压后使用。

### 2. 运行

双击 `Windows系统全能工具箱-v5.0.bat`，在弹出的 UAC 窗口点击「是」。

> [!TIP]
> 如果双击后一闪而过，通常是杀毒软件拦截了提权动作。请右键文件选择 **「以管理员身份运行」**。

### 3. 建议的使用顺序

1. `[1] 清理与空间 → [9] 创建系统还原点`，先留一条后路
2. `[1] 清理与空间 → [1] 一键清理 C 盘垃圾`，先把空间腾出来
3. 需要的话再动第 2 章（更新 / Defender），由轻到重、逐项观察
4. 出问题用第 6 章修复，必要时用第 8 章一键恢复

## 使用说明

| 输入 | 含义 |
| :-- | :-- |
| `1` – `8` | 选择分类（主菜单）或功能（子菜单） |
| `0` | 返回上一级；在主菜单输入 `0` 退出 |
| `Y` / `y` | 确认普通操作 |
| `YES` | 确认高风险操作，需连续输入两次 |
| `N` 或其他 | 取消，不做任何修改 |
| 直接回车 | 等同于退出，避免误触空输入 |

日志文件位于 `C:\ProgramData\WinToolbox\all.log`，格式为 `[时间] 动作名称`，不包含任何个人信息。

## 安全设计

### 一键恢复覆盖范围

| 步骤 | 恢复内容 |
| :-: | :-- |
| 1 / 7 | Windows 更新：服务启动类型、组策略、计划任务 |
| 2 / 7 | Windows Defender：策略、服务、实时防护 |
| 3 / 7 | 桌面外观：小箭头、小盾牌 |
| 4 / 7 | 日期格式、时钟秒数 |
| 5 / 7 | 遥测、广告推荐、经典右键、任务栏 |
| 6 / 7 | 非必要服务、电源计划 |
| 7 / 7 | 自动播放、扩展名、快速访问、照片查看器、Copilot、长路径、内存压缩 |

### 不在恢复范围内的操作

以下操作不可逆或属于按需配置，需要手动控制：

- DISM 组件清理（尤其 `/ResetBase`，清理后无法卸载已安装更新）
- 清理 `Windows.old`、删除还原点
- 磁盘优化与 TRIM、卸载预装应用
- 关闭休眠、关闭保留存储（会改变磁盘空间布局）
- 设置 DNS（属于网络环境选择，恢复后可能影响公司/校园网）

> [!WARNING]
> 执行任何不可逆操作前，请先创建系统还原点并备份重要数据。

## 常见问题

<details>
<summary><b>会不会误删我的文件？</b></summary>

不会。清理项只针对系统缓存目录（临时文件、更新缓存、浏览器缓存、日志、回收站、错误报告），不扫描个人文件夹，也不按扩展名全域删除。
</details>

<details>
<summary><b>关闭更新 / Defender 之后怎么恢复？</b></summary>

`[8] 恢复与日志 → [1] 一键恢复全部设置`。也可以只回到对应分类执行它的“开启”项。
</details>

<details>
<summary><b>Defender 关不掉，提示被系统拒绝？</b></summary>

Windows 10 1903 之后默认开启「篡改防护」。请先到 **Windows 安全中心 → 病毒和威胁防护 → 管理设置** 关闭篡改防护，再重新执行。
</details>

<details>
<summary><b>改了设置但没生效？</b></summary>

界面类设置会自动重启资源管理器；服务与策略类建议重启电脑；部分系统策略在下次登录后生效。
</details>

<details>
<summary><b>清理后空间几乎没变？</b></summary>

被占用的临时文件会在重启后释放。真正占空间的大头通常是休眠文件、`Windows.old`、还原点和 WinSxS，请分别用 `[7]-2`、`[1]-4`、`[1]-8`、`[1]-2`。
</details>

<details>
<summary><b>家庭版系统为什么部分功能无效？</b></summary>

家庭版最低只允许 Basic 级遥测，部分组策略会被系统忽略。这是系统限制，不是工具故障。
</details>

<details>
<summary><b>能在公司电脑上用吗？</b></summary>

可以运行，但「关闭更新」「设置 DNS」「协议栈重置」可能与域策略或内网 DNS 冲突，请先确认所在组织的 IT 规定。
</details>

<details>
<summary><b>支持无人值守批量执行吗？</b></summary>

支持 `--elevated` 参数跳过自提权（用于已提权环境），例如在计划任务中调用：

```bat
cmd /c "Windows系统全能工具箱-v5.0.bat" --elevated
```

菜单仍为交互式。
</details>

| 系统 | 支持情况 |
| :-- | :-- |
| Windows 11（21H2 及以上） | 全部功能 |
